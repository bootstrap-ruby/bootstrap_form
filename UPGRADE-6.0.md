# Upgrading to `bootstrap_form` 6.0

Bootstrap 6 is fundamentally different from previous versions of Bootstrap, and therefore `bootstrap_form` is also fundamentally different.
In addition, we've taken advantage of the major version change to implement new features in `bootstrap_form`
that we hope will make this gem more useful.
Many changes to your code are necessary if you're upgrading from previous versions of `bootstrap_form`.

## Bootstrap 6 Changes

Upgrading `bootstrap_form` to version 6 means you must upgrade your whole application to Bootstrap 6. Read the [Bootstrap 6 migration guide](https://getbootstrap.com/docs/6.0/guides/migration/) to see what changes in Bootstrap 6. This will also help you understand changes you will have to make to your `bootstrap_form` code.
